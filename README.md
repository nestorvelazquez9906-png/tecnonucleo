# TecnoNúcleo - Tienda en Línea de Productos Electrónicos

Plataforma web desarrollada en Laravel para la gestión de catálogo, inventario y usuarios de una tienda de tecnología.

## Requisitos del Sistema
- PHP >= 8.2
- Composer
- Node.js y NPM
- SQLite o MySQL
